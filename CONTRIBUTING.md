# Contributing to Secure Digital Document Management System

Thank you for taking the time to contribute! Contributions are essential to keeping this project secure, scalable, and reliable for legal and investigative document processing.

Please read through these guidelines before submitting a pull request or opening an issue.

---

## Code of Conduct

We expect all contributors to adhere to a respectful and inclusive environment. Please treat team members and reviewers with courtesy and professional respect.

---

## How Can I Contribute?

### 1. Reporting Bugs
- Check the [Issues tab](https://github.com/harshit2k9/SIH26/issues) to ensure the bug hasn't already been reported.
- Use the **Bug Report** template when opening a new issue.
- Clearly describe the steps to reproduce the issue, expected behavior, and environment details.

### 2. Suggesting Features
- Open an issue using the **Feature Request** template.
- Explain the problem your feature solves and the user role it impacts (e.g., Police Officer, Judge, Admin).

### 3. Reporting Security Vulnerabilities
- **Do not publicize security flaws in open issues.**
- Refer to our `SECURITY.md` file for details on reporting security vulnerabilities privately.
